# Tools

=== "Digital Forensics"

    * [**FTK Imager**](https://accessdata.com/products-services/forensic-toolkit-ftk/ftkimager) **~** Imaging tool
    * [**Autopsy**](https://www.autopsy.com/) **~** Opensource end-to-end forensic tool
    * [**Volatility**](https://www.volatilityfoundation.org/) **~** Memory forensics
    * [**Jeffrey's Image Metadata Viewer**](http://exif.regex.info/exif.cgi) **~** Image metadata viewer
    * [**Bulk Extractor**](https://github.com/simsong/bulk_extractor/) **~** Extract information from disk images
    * [**Eric Zimmerman Tools**](https://ericzimmerman.github.io/) **~** A number of tools (Just go look)

=== "Incident Response"

    * [**Velociraptor**](https://docs.velociraptor.app/) **~** Endpoint visibility, triage collection and hunting at scale
    * [**Hayabusa**](https://yamato-security.github.io/hayabusa/) **~** Windows event log timelines and threat hunting with Sigma rules
    * [**VirusTotal**](https://www.virustotal.com/gui/) **~** Check files, hashes, URLs, domains and IPs against many engines
    * [**Houdin.io**](https://houdin.io/) **~** IOC lookups correlated across threat intel sources, with a verdict
    * [**Teoh VPN Detection**](https://ip.teoh.io/vpn-detection) **~** Check whether an IP belongs to a VPN, proxy or hosting provider
    * [**urlscan.io**](https://urlscan.io/) **~** Safely scan a URL and see what the page loads and contacts

=== "General"

    * [**Nmap**](https://nmap.org/) **~** Network discovery and security auditing
