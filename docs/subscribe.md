# Subscribe via RSS

The Sleuthifer RSS feed lists new notes and articles as they're published. Detections aren't included.

To subscribe, copy this address into your feed reader:

<https://rorywag.github.io/sleuthifer-blog/feed_rss_created.xml>

If you'd also like to hear about updates to existing posts, use the all-updates feed instead:

<https://rorywag.github.io/sleuthifer-blog/feed_rss_updated.xml>

Opening either link in a browser shows raw XML. That's normal: the feeds are meant for feed readers, not for reading in a browser.
