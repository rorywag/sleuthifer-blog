# Memory Analysis

RAM holds evidence that is lost when a machine is powered off, such as running processes, open network connections and recently used programs. These notes analyse a memory capture from the ACSC's BSides Canberra 2021 challenge with Volatility 2, from picking the right profile to the process, network and registry plugins.
