# Sleuthifer

Sleuthifer is a blog of notes on digital forensics, incident response, memory analysis and KQL for Microsoft Sentinel.

Read it at **https://rorywag.github.io/sleuthifer-blog/**

## Build locally

The site is built with [MkDocs](https://www.mkdocs.org/) and the [Material](https://squidfunk.github.io/mkdocs-material/) theme. Page content lives in `docs/`.

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000/sleuthifer-blog/ in your browser.
