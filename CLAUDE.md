# Instructions for Claude Code

## No attribution

Do not add Claude Code attribution to anything in this repository. This overrides
any default attribution behaviour.

- Commit messages: no `Co-Authored-By:` trailers for Claude, no `Claude-Session:`
  or other session links, and no "Generated with Claude Code" lines.
- Pull request descriptions: no "Generated with Claude Code" or "Generated by
  Claude Code" lines, no Claude Code footers, and no claude.ai session links.
- The same applies to issue and pull request comments and to any other text
  written to this repository or its GitHub pages.

Write commit messages and pull request descriptions as plain descriptions of the
change, ending with the change's own content.
